# Campusly Student Management

A mock-data Flutter app for basic school administration, built with Material 3.

## Features

- Login screen (demo only; any non-empty username and password work)
- Overview dashboard with student, attendance, and notice summaries
- Student directory with add, edit, and delete actions
- Daily attendance marking for present, absent, and late
- Subject mark entry with calculated averages and estimated GPA
- School announcements and exam schedule notices

## Run

```sh
flutter pub get
flutter run
```

All demo data and edits live in memory and reset when the app restarts. The login
form is for navigation only and does not authenticate against a service.
